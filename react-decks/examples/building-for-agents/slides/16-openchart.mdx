<Notes>
OPENING
- OpenChart is the charting library OpenData uses.
- A chart is a JSON object. This is the README's bar chart.
- Mark is bar, popularity maps to x, language maps to y.
- Engine computes scales, ticks, layout. Because the chart is data, it can be validated before anything is drawn.

[click] CLICK 1
- The y field is misspelled: langauge.
- Middle tile is what validateSpec returned when this page loaded.
- Path is a JSON Pointer to the field.
- Code is a fixed string an agent can match.
- Suggestion lists the columns and proposes the closest by edit distance.
- Validator is about 3,400 lines of TypeScript, no schema library.

[click] CLICK 2
- Spelled language: valid, no errors. The Vue component draws the chart from the same object.
- Spec is also published as JSON Schema, generated from the TypeScript types. CI fails if it's out of date.

[click] CLICK 3
- Six packages. Bars are TypeScript lines, excluding tests.
- Core: types and theme.
- Engine: about 50,000 lines. Validates specs, computes layout, no DOM code.
- Vanilla draws to the DOM and can render SVG on a server.
- React, Vue and Svelte wrap vanilla. React is about 5 percent of the engine's size.
- The spec type has 19 marks.

IF ASKED
- CLI or MCP server? No. It's a library. Agents reach it through OpenData's MCP server.
- Version? 9.0.0.
</Notes>
