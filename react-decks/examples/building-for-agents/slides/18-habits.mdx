OPENING
- Six habits, seven tools. A cell is lit only where I can point to a file in that product's repo.
- Rows 1 and 2, output: six tools print JSON a program can parse, and the same six print the next step.
- Stacks and StatGlass put a next field in the error.
- foreman ends a result with the next command.
- OpenChart suggests the field you probably meant.

[click] CLICK 1
- Rows 3 and 4, finishing.
- Stacks, foreman and StatGlass document exit codes, one action per code.
- Three tools have a command that checks the work: Stacks verify, a foreman contract's must-pass commands, Decks check and lint.

[click] CLICK 2
- Rows 5 and 6, several agents and docs.
- I run two to four agents at a time.
- rr locks a host per run. foreman gives each task a worktree. Decks picks a free port per screenshot run.
- Five tools ship their own instructions.
- Stacks, foreman and StatGlass print a guide and install a skill from the binary, so the text matches the installed version.

[click] CLICK 3
- Any CLI or library can adopt these. None of them calls a model.
- They're output formats, exit codes, locks and bundled docs.
- A JSON flag, a next field and a documented exit table can go into a tool you already maintain.

IF ASKED
- Why are some cells dark? Lit only with a file behind it. rr returns the remote command's exit code, so no exit table. OpenChart's validator is a function with no command around it.
