<Notes>
OPENING
- First user is me: rr running OpenData's tests across three machines, pretty flag on.
- One line per task with host and time, totals at the end.
- I read the totals, see two failed, scroll up to those two.
- Designing this view is developer experience.

[click] CLICK 1
- Second user is a coding agent, and it gets the whole stream.
- Same output as bytes, escape character written out.
- Each coloured value is wrapped in two escape sequences.
- My terminal makes colour. An agent gets text that takes up context.

[click] CLICK 2
- Without the pretty flag, rr prints JSON.
- One event per phase on stderr, one result event at the end.
- Result holds status, exit code, each failing test with file and message.
- JSON is the default. A person adds the flag.
- Designing this output is agent experience.

IF ASKED
- Why different totals? Suite ran twice, 32 minutes apart. The end-to-end task failed in the first run, passed in the second.
</Notes>
