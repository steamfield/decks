# @steamfield/decks

React slide decks with MDX, motion components and a Vite development server. Requires Node 22.12 or later and React 19.

```sh
bun add @steamfield/decks react@19.3.1 react-dom@19.3.1
decks dev path/to/deck
decks build path/to/deck
```

Import runtime components and deck types from `@steamfield/decks`, motion components from `@steamfield/decks/motion`, kit components from `@steamfield/decks/kit`, and `defineDeck` from `@steamfield/decks/node`. Import `@steamfield/decks/kit/styles.css` for the kit styles and self-hosted Inter fonts.

The installed `docs/` directory contains the guide for this version.
